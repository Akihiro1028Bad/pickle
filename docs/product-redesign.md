# Pickle [仮] — 市場調査を踏まえた再設計メモ

> 作成日: 2026-06-09
> 前提: 2026年時点の国内ピックルボール競技人口は約33万人、認知率13.1%、潜在プレイヤー約1,189万人という公開調査を踏まえる。

## 1. 結論

本アプリは **「イベントを探すサービス」ではなく「今日・今週打てる相手を探す個人募集アプリ」** として再定義する。

既存サービスはイベント、練習会、サークル、大会、コート検索に寄っている。差別化余地は、個人が短時間で「誰か打ちませんか」を出せる即時性と軽さにある。

## 2. 新しいポジション

| 項目 | 再設計後 |
|---|---|
| 一言 | ピックルボールの個人単発募集アプリ |
| コア用途 | 今日・明日・週末に一緒に打つ相手を探す |
| 初期検証 | PBT / 首都圏で投稿密度を作る |
| 提供範囲 | 全国対応。ただし初期の供給づくりは施設・地域単位で集中 |
| 競合との差 | イベント参加ではなく、個人の空き時間マッチング |

## 3. ターゲット

優先ターゲットは **20〜40代のテニス・バドミントン・卓球経験者**。理由は、認知率が若年〜ミドル層で高く、アプリで投稿/DMする行動にも乗りやすいため。

50代以上も競技人口として重要だが、初期UXは「スマホで募集を出す」「DMで調整する」に慣れた層から立ち上げる。施設内QRやスタッフ導線で50代以上にも広げる。

## 4. 勝ち筋

### 勝てる条件

- 投稿粒度を「イベント」ではなく「1回打つ」に絞る
- 全国対応でも、初期は地域/施設ごとに投稿密度を作る
- 投稿は30秒で出せる
- 一覧では「いつ・どこで・何人・レベル」が一目で分かる
- 返信/成立までDMで完結する
- 古い募集は自然に下がる、または自動クローズする

### 負ける条件

- イベント検索、コート検索、サークル検索、大会検索まで広げる
- フリーテキストだけで検索性を捨てる
- 全国に広げた結果、各地域の投稿が薄くなる
- 投稿後の返信率、ドタキャン、安全性を管理しない

## 5. プロダクト方針

### 入力は「最小構造化 + 自由本文」

完全フリーテキストは投稿ハードルが低い一方、全国化すると検索できなくなる。したがって、検索に必要な情報だけ選択式にする。

| 項目 | 必須 | 目的 |
|---|---:|---|
| 都道府県/エリア | 必須 | 全国対応の検索軸 |
| 場所/施設名 | 必須 | 現地集合の明確化 |
| 日時 | 必須 | 鮮度と当日募集の判定 |
| 募集人数 | 任意 | 1人募集・ダブルス募集を判別 |
| レベル感 | 任意 | ミスマッチ防止 |
| 本文 | 必須 | 温度感、料金、持ち物、補足 |
| 表示時間 | 必須 | 古い募集を残さない |

### 主要画面

| タブ | 役割 |
|---|---|
| 募集 | 個人募集の一覧/詳細/作成 |
| コート | 近くのコート/外部予約導線。MVPではPBTなど提携施設から開始 |
| メッセージ | 投稿経由の1対1 DM |
| プロフィール | レベル、DUPR、自己紹介、通報/ブロック管理 |

## 6. MVPスコープ

MVPは以下に絞る。

- 全国の地域選択
- 投稿作成: 地域、場所、日時、募集人数、レベル感、本文、表示時間
- 投稿一覧: 地域フィルタ、今日/明日/週末、レベル、募集中/締切
- 投稿詳細: 本文、募集条件、DM CTA
- 投稿経由のDM
- 通報/ブロック/モデレーション
- 運営投稿/おすすめ投稿
- PBTなど初期提携施設の予約リンク

決済、参加承認、公開コメント、サークル管理、大会管理、コート在庫管理はMVP外。

## 7. 初期グロース

全国アプリとして作るが、最初から全国の全地域で投稿を期待しない。以下の順で密度を作る。

1. PBT / 本八幡周辺
2. 東京・千葉・神奈川・埼玉のピックルボール施設
3. 関西/東海など既存サークルが強い地域

施設内QR、予約完了後の案内、Instagram、公式LINE、体験会後の導線を使い、「その施設で今日打つ人を探す」導線を作る。

## 8. 判断

この再設計なら、競合のイベント型サービスとは正面衝突しにくい。勝ち筋は **全国のイベントDB** ではなく、**地域ごとの個人募集密度** にある。

プロダクト名・コピーも「Match」単体より、即時性が伝わる表現を優先する。

- 候補: Pickle Board
- 候補: Pickle Match Board
- 候補: 今日ピク
- コピー: イベントじゃなく、今日の相手を見つける。
- コピー: 1人で来ても、すぐ打てる。
