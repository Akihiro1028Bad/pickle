## 2. デザイントークン（実測値）

### カラーパレット
| 役割 | 値 | 用途 |
|---|---|---|
| `--bg` ベース背景 | **`#0A0A1A`**（rgb 10,10,26 / 深い宇宙ネイビー） | 画面全体の地 |
| `--bg-deep` | `#06060F` | スマホ画面内・最暗部 |
| `--surface` 面 | `#14141F` | カード・パネル |
| `--surface-2` | `#1C1C2B` | チップ・1段持ち上げ面 |
| `--court`（深ネイビーパネル） | `#171728` / `#24243C` | 施設カード・プロフィールカバー等の暗色ヒーロー面 |
| `--accent` ネオンイエロー | **`#F6FF54`**（rgb 246,255,84） | 主要CTA・強調・ハイライト（**シグネチャー**） |
| `--ink-on-accent` | `#000000` | 黄背景上の文字（必ず黒） |
| `--text` 主テキスト | `#E6E6E6` | 本文・見出し |
| `--text-muted` | `#8A8A8A` | 補助テキスト |
| `--white` | `#FFFFFF` | 最強調テキスト |
| （差し色）ブルー | `rgba(48,110,195,*)` ごく僅か | 限定的なアクセント 🔸 |

> ⚠️ 現行モック(v0.3)のクリーム/コートグリーン/ライム系は**全廃**し、上記へ置換する。
> ライム(`#D9F25C`)はネオンイエロー(`#F6FF54`)に最も近いので、役割を引き継がせる。

### タイポグラフィ
| 役割 | 書体 | 備考 |
|---|---|---|
| ディスプレイ / 見出し | **Orbitron**（fallback: Inter） | 宇宙的・テクノ。英字大文字の巨大見出しで使用 |
| 本文 / UI | **Inter** + **Noto Sans JP**（Hiragino フォールバック） | 可読性重視 |
| セクションラベル | Orbitron 900 / 大文字英字 | 例：CONCEPT, FACILITY, SERVICES, PRICING |

> 現行の Fraunces（セリフ）・Manrope・Zen Kaku は廃止。
> 日本語は Noto Sans JP に統一。

### 形状・質感
- **角丸はシャープに**：ボタンは `border-radius: 0`（一部 4px）。現行の大きな角丸(14〜18px)は縮小/廃止。
- ボタン：**ネオンイエロー地 × 黒文字**を主CTAの基本形に。
- 大きな英字大文字の見出し（72px / weight 900 級）でセクションを宣言。
- 背景はフラットな暗色面。ノイズや暖色グラデは廃止し、必要なら**ネオングロー/微発光**で宇宙感を出す 🔸。

## 4. ブランドの打ち出し（再設計後）

- **独自サービス名を検討する。** 全国対応にする場合、PBTロゴのみでは地域が限定されて見えるため、アプリ名は中立名に寄せる。
  - 候補：`Pickle Board` / `Pickle Match Board` / `今日ピク`
  - PBT導線では `Partner Court` / `Powered by PBT` / `PBTで募集` のように施設文脈で使う。
  - 旧案：アプリ内ヘッダー `PBT` + `MATCH` は、PBT専用版または提携施設LPでは継続利用可。
  - マーケ面/ヒーロー：`イベントじゃなく、今日の相手を見つける。`
  - ✅ PBT公式ヘッダーロゴ（横型ネオン `yoko-neon.png`）を bigban プロジェクトから取得し配置済み。
    - 配置：`pickle/public/logos/`（アプリ正規置き場）＋ `pickle/docs/mockups/assets/`（モック参照用）
    - 併せて `mark-neon.png` / `yoko-w.png` も取得済み。
    - v0.4ではアプリヘッダー(画面01)＋マーケ面ヒーローに実ロゴを使用。
- コピーは PBT のトーン（ビッグバン/ムーブメント）を引用：
  - 採用：「**Small Dink, Big Match.**」
- PBT専用画面・施設リンクではPBTへのリンク・提携表記を出す。
